# test-project

Starter Node.js app by **Nirob**. The intended stack is **TypeScript** and **Next.js** (App Router).

## Stack

- Node.js
- TypeScript
- Next.js (App Router) + React
- npm

## Requirements

- Node.js 18 or later
- npm

## Setup

```bash
npm install
```

When the Next.js app is in place:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
npm test
```

## Layout

```text
app/           # routes, layouts, pages
components/    # reusable UI
lib/           # shared helpers
public/        # static assets
```
